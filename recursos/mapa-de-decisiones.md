# Mapa de decisiones

**Herramienta 4 de 18 · Capítulo 7 · Etapa E del Método LEGADO · Versión 1.0**

---

## 1. Para qué sirve

Para encontrar **las decisiones que están escondidas dentro del trabajo diario** y cuya
resolución depende hoy de una sola persona.

Conviene decir qué mide y qué no mide. **Mide concentración, no capacidad.** Que una decisión
vuelva una y otra vez a la misma persona no significa que nadie más sepa pensar: significa que hoy
otra persona no tiene a mano el criterio, la historia, la información o el contexto para
resolverla igual.

Y distingue tarea de decisión, que no es lo mismo que fácil y difícil. **Una tarea exige
saber qué hacer y cómo hacerlo. Una decisión exige, además, hacer visible qué se mira y con
qué criterio se elige.** Esta hoja localiza esas decisiones y deja escrito lo mínimo para
poder trabajarlas después.

**Lo que no hace:**

- **No escribe el criterio completo.** Anota su etiqueta en una frase y para ahí. El porqué
  entero se documenta más adelante, con su propio instrumento.
- **No reparte autoridad.** No dice quién podrá aprobar qué ni hasta qué importe. Registra
  quién decide **hoy**, y solo cuando haga falta para entender el mapa.
- **No evalúa a nadie.** Localiza un punto de decisión, no una carencia.
- **No puntúa.**

## 2. Cómo se usa

| | |
|---|---|
| **Quién la completa** | La persona de quien depende el negocio. |
| **Con qué material** | **Los tres primeros elementos** de su inventario del conocimiento crítico, y el trazo del proceso real de cada uno. |
| **Cuánto se tarda** | Media hora por elemento. |
| **Cada cuánto** | Cuando se incorpore un elemento nuevo del inventario. |
| **Qué hace falta** | Papel. Nada más. |

**No empiece por aquí.** Si no tiene el inventario del capítulo 6, esta hoja se convierte en
una lista de todas las decisiones del negocio, que no termina nunca.

## 3. La tabla

Una fila por decisión. Puede haber más de una decisión dentro del mismo elemento.

| Dependencia | Cuándo aparece | Qué hay que decidir | Qué se mira | Criterio, en una frase | Si no se decide | Qué falta extraer |
|---|---|---|---|---|---|---|
| | | | | | | |
| | | | | | | |

**Cuándo aparece.** El punto del proceso real, no una hora del día: «al preparar el
presupuesto», «cuando llega el pedido incompleto».

**Qué se mira.** La información concreta que usted consulta o recuerda antes de resolver.
Si la respuesta es «nada, lo sé», escríbalo: es un hallazgo.

**Criterio, en una frase.** Una etiqueta, no una explicación. «Según el historial del
cliente» está bien. «Según el historial del cliente, entendiendo por historial los últimos
tres años, salvo si hubo un impago, en cuyo caso…» **no va aquí**: eso es el manual de
criterio y tiene su propio capítulo.

**Si no se decide.** Qué ocurre mientras nadie la toma: se para algo, se retrasa, se
resuelve peor, se pierde una oportunidad.

**Qué falta extraer.** Una palabra: *criterio*, *información*, *historia*, *excepciones*, o
la combinación que sea. Es la lista de trabajo para los capítulos siguientes.

## 4. Cómo buscarlas

**Con equipo:** ¿qué decisiones **siguen subiendo** hasta usted? No se pregunta quién no sabe
decidir. Se mira dónde vuelve a aparecer la misma consulta.

**Trabajando solo:** nada sube, así que se busca en otros sitios.

- Decisiones que **vuelve a pensar cada vez**, aunque ya las haya resuelto muchas veces.
- Condiciones que aplica y **nunca ha escrito**.
- Lo que alguien que le sustituyera dos semanas **no podría reconstruir** con lo que hay.

## 5. Un cuidado importante

Al recorrer las decisiones aparecerán documentos: un procedimiento, una plantilla, una
instrucción antigua. **No dé por resuelta la decisión porque exista el papel.**

Un procedimiento dice qué pasos dar. Decir cuándo se aplica y por qué es otra cosa, y hay
que comprobarlo documento por documento. Si al mirarlo piensa «esto está escrito, pero nadie
sabría usarlo sin preguntarme», anótelo en la última columna como *criterio*. Es el hallazgo
más útil de esta hoja.

Y lo mismo al revés: **una decisión poco frecuente puede ser la más crítica.** Algo que se
resuelve una vez al año y solo sabe resolverlo una persona pesa más que algo que se resuelve
a diario y está claro. No ordene esta hoja por número de veces.

## 6. Lo que se lleva escrito

> **Estas son las decisiones que todavía dependen de mi criterio.**

Y, de todas ellas, **marque las tres que llevaría primero al trabajo de documentar**. Los
criterios de esas tres son el material del capítulo 9.

**Siguiente acción, una sola:** durante las dos próximas semanas, cada vez que tome una de
las decisiones de esta hoja, escriba en el margen **la frase que se dijo a sí mismo para
resolverla**. Sin ordenarla, sin pulirla y sin convertirla en regla. Solo la frase, tal como
le salga. Cuando llegue al capítulo 9 va a agradecer tener esas frases en crudo.

## 7. Un ejemplo

Un hombre que dirige un pequeño taller de reparación de maquinaria trabaja el primer
elemento de su inventario: *«cuándo se acepta un trabajo urgente»*.

| | |
|---|---|
| **Dependencia** | Cuándo se acepta un trabajo urgente |
| **Cuándo aparece** | Al entrar una petición fuera de la planificación de la semana |
| **Qué hay que decidir** | Si entra, y qué se desplaza para que entre |
| **Qué se mira** | Qué hay comprometido esos días, quién lo pide y si es la primera vez que lo pide |
| **Criterio, en una frase** | Se acepta si no desplaza a un cliente que ya esperó otra vez |
| **Si no se decide** | El cliente llama otra vez, y a veces se va |
| **Qué falta extraer** | Criterio, y las excepciones |

Le salen otras dos decisiones dentro del mismo elemento, y una de ellas le sorprende: cuando
acepta un urgente, alguien tiene que avisar al cliente desplazado, y **cómo se le avisa**
también es una decisión, con su criterio propio. Nunca la había pensado como decisión.

No escribe qué es «haber esperado otra vez», ni cuántas veces, ni qué clientes están fuera de
esa regla. Anota la etiqueta y sigue.

## 8. Límites de esta herramienta

1. **No está validada.** Se construyó para este libro.
2. **Solo ve lo que usted reconoce como decisión.** Lo que resuelve sin notarlo puede quedar
   fuera, y aparecer más adelante.
3. **No documenta el criterio, y por diseño.** Si empieza a hacerlo, esta hoja se convierte
   en otra cosa y se queda a medias.
4. **No reparte autoridad.** Quién decidirá mañana es un asunto posterior.
5. **Una decisión anotada no es una decisión resuelta.** Localizar no es transferir.

> Esta herramienta es material educativo. No constituye asesoría legal, fiscal, laboral,
> financiera, contable, regulatoria ni de ciberseguridad. Los límites de autoridad, la
> conservación de documentos y el tratamiento de datos personales deben definirse con
> profesionales competentes según la jurisdicción de cada empresa.
