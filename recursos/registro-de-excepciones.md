# Registro de excepciones

**Herramienta 6 de 18 · Capítulo 8 · Etapa E del Método LEGADO · Versión 1.0**

---

## 1. Para qué sirve

Para dejar por escrito **los casos en que el negocio se aparta de su forma normal de
trabajar, y por qué**.

Se usa en dos tiempos, y el orden no es un detalle:

| | |
|---|---|
| **Fase 1 — El hecho** | Qué pasó. Se escribe sin opinar. |
| **Fase 2 — El juicio** | Qué hacemos con ello. Se escribe **en una revisión separada y con distancia**, no en el mismo momento. |

Quien juzga mientras describe acaba escribiendo una justificación en lugar de un registro.

**Lo que esta hoja no hace:**

- **No escribe el criterio completo.** Anota el motivo en una frase. Si necesita media
  página, se marca y se deja para el manual de criterio.
- **No reparte autoridad.** Registra quién decidió aquel día; no dice quién podrá autorizar
  excepciones mañana.
- **No persigue a nadie.** Una excepción no es una falta. Es información.
- **No puntúa.**

## 2. Tres cosas que se confunden

| | |
|---|---|
| **Excepción** | Existe una forma normal y un caso concreto hace que se actúe de otra manera. **La forma normal no tiene que estar escrita**: basta con que exista. |
| **Error** | Una actuación que no debería repetirse en las mismas condiciones. **Vista por primera vez se parece a una excepción**, y por eso no se etiqueta al observarla. |
| **Falta de regla** | Cada caso se resuelve desde cero, sin referencia común. Ahí no hay excepción: **falta la norma**. Anótelo así y siga. |

**Y una cuarta que no entra aquí.** Si su trabajo consiste en hacer cada encargo a medida, la
variación no es excepción: es el oficio. La pregunta que separa: **¿esto se aparta de cómo
resuelvo normalmente las situaciones comparables?** Si no, no se registra.

## 3. Cómo se usa

| | |
|---|---|
| **Quién la completa** | Quien conozca el caso. Con equipo puede completarla más de una persona. |
| **Por dónde se empieza** | Por las marcas «normalmente esto es así, pero…» que dejó al margen en el capítulo 7. |
| **Cuánto se tarda** | Pocas frases por excepción. Si una le lleva más, márquela y siga. |
| **Cada cuánto** | La fase 1, cuando ocurre o cuando se recuerda. La fase 2, en otro momento. |
| **Qué hace falta** | Papel. |

**No intente reconstruir la historia entera del negocio.** Empiece por las marcas que ya
tiene y añada después lo que vaya apareciendo.

## 4. Fase 1 — El hecho

| Situación | Forma normal | Qué se hizo distinto | Motivo | Resultado observado | Quién lo decidió |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |

**Motivo.** Una frase. Y si no se sabe, se escribe **«motivo no conocido»**: es una respuesta
legítima y de las más útiles de esta hoja. **No invente una explicación razonable a
posteriori**, porque convierte una laguna en una regla falsa que además queda por escrito.

**Resultado observado.** Lo que se vio, no lo que se concluye. «El cliente aceptó y pagó a
los treinta días» es un resultado. «La excepción funcionó» es una interpretación, y desde un
caso no se sostiene: no escriba que una cosa causó la otra.

**Quién lo decidió.** Descriptivo, para entender el caso. No es una asignación de autoridad.

## 5. Fase 2 — El juicio

En una revisión aparte, con distancia y con la fila delante. **Trabajando solo, conviene que
pase tiempo**; no hay un plazo correcto.

| Excepción | ¿Sigue teniendo sentido? | Clasificación | Hasta cuándo | Quién vuelve a mirarlo | Siguiente paso |
|---|---|---|---|---|---|
| | | | | | |

**Clasificación**, cuatro posibilidades:

| | |
|---|---|
| **Se mantiene** | La razón sigue viva y sigue siendo buena. |
| **Es temporal** | Vale mientras dure una condición concreta. Se retira cuando esa condición termine. |
| **Hay que mirarla** | No hay información suficiente todavía. Aquí van casi todas las de motivo desconocido. |
| **Debería dejar de hacerse** | Ya no tiene razón, o nunca la tuvo. |

**Ese cuarto casillero es el que da sentido a los otros tres.** No toda excepción se
conserva, y un registro que solo legitime lo que ya se hacía no sirve para nada.

**Dos frases que no bastan como motivo:** «siempre lo hemos hecho así» describe una
costumbre, no una razón; «funcionó aquella vez» describe un caso, no una regla.

**Hasta cuándo.** No tiene que ser una fecha. Puede ser una condición —«mientras dure este
proyecto»— y puede ser «sin plazo, se revisa». **Lo que no puede es quedar en blanco:** una
excepción sin horizonte **puede mantenerse por inercia** mucho después de que su razón se
acabe.

**Quién vuelve a mirarlo.** No es quien aprueba: es quien comprobará si esto sigue teniendo
sentido. **Con equipo**, alguien que participe en ese trabajo. **Trabajando solo**, usted
mismo — y conviene reconocer que **eso es más débil**, porque quien registró y quien revisa
son la misma persona y no hay mirada independiente. Lo que ayuda es la distancia: registrar
dentro de la situación y volver cuando ya está fuera. **No se inventa un revisor que no
existe.**

## 6. Dos hallazgos que no son excepciones

**Puede ser una regla sin escribir.** Si el mismo apartamiento se repite bajo las mismas
condiciones y por el mismo motivo, quizá ya no sea un caso especial: es cómo se trabaja, y no
está anotado. **Lo que lo sugiere es el patrón, no el número de veces**: una excepción anual
puede seguir siendo excepción, y una semanal puede ser una regla encubierta. **El patrón lo
sugiere; compruébelo antes de convertirlo en regla.**

**O puede ser la forma normal, que está mal.** Si hay que apartarse continuamente de lo
previsto para que el trabajo salga, el problema puede estar en lo previsto. **Anótelo y no lo
arregle ahora**: cambiar el procedimiento base se decide con todo el registro delante.

## 7. Lo que no se negocia

Una excepción interna no autoriza a apartarse de una ley, una obligación regulatoria, un
requisito de licencia, una norma de seguridad, un contrato firmado ni las normas de una
profesión.

Si al registrar una excepción aparece cualquiera de esos ámbitos, **márquela y consúltela con
quien corresponda antes de seguir aplicándola**. Que lleve años haciéndose no la vuelve
admisible.

## 8. Por dónde empezar, sin puntuar

**No puntúe.** No hay un riesgo siete sobre diez. Y **no ordene por frecuencia**: una
excepción que ocurre una vez cada varios años puede ser la más crítica, y una frecuente puede
tener poco impacto.

Mire primero las que cumplan alguna de estas condiciones:

- Su motivo vive **en una sola persona**.
- De ellas depende una decisión importante.
- Afectan a una relación de las que anotó como críticas.
- **Su razón no está clara.**
- Podrían rozar una obligación externa.

No es un algoritmo ni está validado: es por dónde conviene empezar.

## 9. La siguiente acción

> **Separe las excepciones cuyo motivo no le cabe en una frase.**

Esas son las que necesitan que alguien explique el porqué entero, y son la materia prima del
capítulo siguiente. Júntelas con las frases en crudo que lleva recogiendo desde el capítulo 7.

**No escriba todavía ese porqué.** Llegar al capítulo 9 con las excepciones registradas, los
motivos breves, las dudas abiertas y las frases sin pulir es exactamente la mejor manera de
llegar.

## 10. Un ejemplo

Un hombre que lleva una explotación agrícola con cuatro personas empieza por dos marcas.

| | |
|---|---|
| **Situación** | Un comprador antiguo pide adelantar la recogida de su pedido |
| **Forma normal** | El orden de recogida sigue el orden de los compromisos |
| **Qué se hizo distinto** | Se le adelantó, desplazando a otro |
| **Motivo** | Motivo no conocido. «Con él siempre se hace así» |
| **Resultado observado** | El pedido salió. El otro comprador no dijo nada |
| **Quién lo decidió** | Él |

En la fase 2, tres semanas después, aparece lo que faltaba: aquel comprador tuvo una avería
grave hace años y se le ayudó entonces, y desde entonces se le adelanta. La razón existió y
tuvo sentido. Hoy, ninguno de los dos se acuerda de por qué sigue.

Lo clasifica como **hay que mirarla**, pone «se revisa antes de la próxima campaña» y anota
en el siguiente paso: *hablar con él y decidir si esto sigue o se retira*. No lo retira ese
mismo día, y hace bien: una excepción de años se retira hablando, no tachando.

La segunda marca la resuelve en dos líneas y la clasifica como **se mantiene**.

## 11. Límites de esta herramienta

1. **No está validada.** Se construyó para este libro; las cuatro clasificaciones son
   criterios de lectura, no una escala.
2. **Escribir una excepción no la transfiere.** Otra persona puede leer la fila entera y aun
   así no saber **cuándo** aplicarla: ese reconocimiento es criterio, y le falta el capítulo
   siguiente.
3. **Solo recoge lo que alguien reconoce como apartamiento.** Lo que ya se ha vuelto
   costumbre puede no aparecer, y puede salir más adelante.
4. **No decide qué es admisible.** Sobre todo cuando hay ley, contrato o seguridad de por
   medio.
5. **Trabajando solo, el revisor no es independiente**, y eso limita lo que la fase 2 puede
   corregir.

> Esta herramienta es material educativo. No constituye asesoría legal, fiscal, laboral,
> financiera, contable, regulatoria ni de ciberseguridad. Los límites de autoridad, la
> conservación de documentos y el tratamiento de datos personales deben definirse con
> profesionales competentes según la jurisdicción de cada empresa.
