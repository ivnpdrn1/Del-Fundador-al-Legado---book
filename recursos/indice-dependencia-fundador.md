# Índice de Dependencia del Fundador

**Herramienta 1 de 18** · Capítulo 1 · Etapa **L** del Método LEGADO
**Versión:** 1.0 · **Fecha:** 2026-09-06

---

## 1. Propósito

Convertir una sensación —«aquí todo pasa por mí»— en un número que pueda anotarse,
archivarse y volver a calcularse dentro de seis meses con las mismas preguntas.

El índice sirve para tres cosas y solo para tres:

1. **Situar el punto de partida.** Un valor inicial fechado.
2. **Localizar dónde se concentra la dependencia.** Es lo más útil de todo el instrumento.
   Dos empresas con el mismo total pueden necesitar trabajos completamente distintos.
3. **Medir el avance.** El mismo cuestionario, repetido, es la prueba de que el método
   funcionó o de que no funcionó.

**Para lo que no sirve:** no mide la calidad de la gestión, ni la salud financiera, ni la
capacidad del equipo, ni el valor de la empresa. Una dependencia alta es compatible con
una empresa excelente. De hecho, es lo más habitual.

## 2. Advertencia sobre su naturaleza

Este índice **no es un instrumento validado científicamente**. Se construyó para este
libro. No ha sido sometido a validación académica, no procede de una muestra estadística y
no existe ninguna investigación que respalde sus umbrales. Sus rangos son criterios de
lectura razonables, no hallazgos.

En consecuencia, **su resultado no es comparable con el de otra empresa.** Solo es
comparable consigo mismo a lo largo del tiempo. Cualquier uso distinto —comparar
compañías, certificar, calificar a una persona— excede lo que este instrumento puede
sostener.

## 3. Instrucciones

1. **Lo responde el propietario o la propietaria.** Veinte minutos aproximadamente.
2. **Responda sobre lo que ocurre, no sobre lo que debería ocurrir.** Es la única
   instrucción que decide si el resultado sirve de algo.
3. **Piense en las últimas cuatro semanas**, no en un mes excepcional ni en cómo era la
   empresa hace años.
4. **No consulte a nadie mientras responde.**
5. **Recomendado:** pida a una persona de su confianza —dirección, administración, un
   familiar no operativo— que responda el mismo cuestionario por separado, pensando en
   usted. Las diferencias entre las dos respuestas suelen ser más informativas que el
   número.
6. **Feche el resultado y archívelo.** Sin fecha, el instrumento pierde su función
   principal.
7. **Repita a los seis meses.** Antes es pronto para ver cambios; más tarde se pierde el
   hábito.

## 4. Escala de respuesta

La misma para las veinticuatro preguntas. Elija el valor que mejor describa la realidad.

| Valor | Significado |
|---|---|
| **0** | Nunca o casi nunca. Otras personas lo hacen habitualmente sin usted. |
| **1** | A veces. Otras personas pueden hacerlo, aunque suelen consultarle. |
| **2** | Con frecuencia. Solo se hace con su aprobación previa. |
| **3** | Siempre. Solo usted. |

## 5. Cuestionario

Ocho dimensiones, tres preguntas cada una. Anote el valor a la derecha.

### A. Decisiones y autorizaciones

| # | Pregunta | 0-3 |
|---|---|---|
| 1 | Las decisiones que se apartan de lo habitual, ¿las toma usted? | |
| 2 | Los compromisos de gasto, ¿esperan su autorización aunque el importe sea moderado para la empresa? | |
| 3 | Cuando dos áreas o dos personas discrepan, ¿lo resuelve usted? | |

### B. Conocimiento y criterio

| # | Pregunta | 0-3 |
|---|---|---|
| 4 | El motivo por el que las cosas se hacen de una manera y no de otra, ¿existe solo en su memoria? | |
| 5 | Ante una situación nueva, ¿es usted quien sabe qué hay que mirar primero? | |
| 6 | Si una persona con experiencia se marchara mañana, ¿tendría usted que asumir personalmente su trabajo? | |

### C. Relaciones externas

| # | Pregunta | 0-3 |
|---|---|---|
| 7 | Los clientes principales, ¿esperan tratar con usted los asuntos importantes? | |
| 8 | Los proveedores críticos, ¿negocian condiciones únicamente con usted? | |
| 9 | ¿Se enfriarían esas relaciones si usted dejara de atenderlas durante unos meses? | |

### D. Operación y resolución de problemas

| # | Pregunta | 0-3 |
|---|---|---|
| 10 | Cuando surge un problema no previsto, ¿termina resolviéndolo usted? | |
| 11 | ¿Recibe consultas rutinarias que otra persona podría responder con la información disponible? | |
| 12 | ¿Interrumpe su propio trabajo para desbloquear el de otros? | |

### E. Información y acceso

| # | Pregunta | 0-3 |
|---|---|---|
| 13 | Para responder una pregunta sobre el negocio, ¿hay que preguntárselo a usted? | |
| 14 | Los datos importantes, ¿están repartidos en sitios que solo usted sabe conciliar? | |

### F. Dinero y controles

| 16 | ¿Revisa usted personalmente los movimientos de dinero? | |

### G. Excepciones y acuerdos no escritos

|---|---|---|

| 20 | ¿Existen acuerdos con clientes, proveedores o personas que no constan por escrito? | |

## 6. Puntuación

**Paso 1. Subtotal por dimensión.** Sume las tres preguntas de cada bloque. Cada dimensión

| Dimensión | Subtotal (0-9) | Nivel |
|---|---|---|
| A. Decisiones y autorizaciones | | |
| B. Conocimiento y criterio | | |
| C. Relaciones externas | | |
| D. Operación y resolución de problemas | | |
| E. Información y acceso | | |
| F. Dinero y controles | | |
| G. Excepciones y acuerdos no escritos | | |
| H. Supervisión y continuidad | | |
| **Total** | **/72** | |

**Paso 2. Nivel de cada dimensión.**

| Subtotal | Nivel de la dimensión |
|---|---|
| 0-2 | Baja |
| 3-5 | Moderada |
| 6-7 | Alta |
| 8-9 | Crítica |

**Paso 3. Índice global.** Sume los ocho subtotales. El resultado va de 0 a 72.

## 7. Interpretación del resultado global

| Índice | Nivel | Qué significa |
|---|---|---|
| **0-17** | Dependencia baja | La empresa funciona con criterios conocidos por más de una persona. Su presencia aporta valor, pero no es un requisito de la operación. El trabajo pendiente es de sostenimiento: que no se degrade. |
| **18-35** | Dependencia moderada | La empresa resiste ausencias cortas. Existen zonas concretas —normalmente una o dos dimensiones— donde todo vuelve a usted. El trabajo es quirúrgico, no general. |
| **36-53** | Dependencia alta | La empresa funciona bien **porque** usted está. Una ausencia de una semana produce retrasos, errores silenciosos y desgaste del equipo. Es el resultado más frecuente en empresas maduras bien dirigidas, y el punto de partida habitual de este libro. |
| **54-72** | Dependencia crítica | La operación y el criterio están concentrados en una sola persona. Una ausencia imprevista y prolongada pondría en riesgo relaciones, ingresos y continuidad. Conviene empezar por lo esencial, no por lo ideal. |

**Sobre el número.** No lo interprete con más precisión de la que tiene. Una diferencia de
dos o tres puntos entre dos mediciones no significa nada: puede deberse al ánimo del día.
Una diferencia de diez puntos sí significa algo.

## 8. Cómo leer el perfil, que es lo que importa

El total dice cuánto. El perfil por dimensiones dice **por dónde empezar**. Localice sus
dos dimensiones más altas y siga la fila correspondiente.

| Dimensión más alta | Qué está ocurriendo | Por dónde empezar |
|---|---|---|
| **A. Decisiones** | No hay límites escritos de autoridad. Todo sube por costumbre. | Matriz de autoridad y aprobaciones (cap. 10). |
| **B. Conocimiento** | El criterio no ha salido nunca de su cabeza. | Inventario del conocimiento crítico (cap. 6) y Manual de criterio (cap. 9). |
| **C. Relaciones** | Los vínculos externos son personales, no de la empresa. | Mapa de relaciones críticas y segundo contacto interno (cap. 7). |
| **D. Operación** | La empresa funciona por interrupciones. | Registro de interrupciones (cap. 1) y delegación por bloques (cap. 18). |
| **E. Información** | No hay una fuente única de datos fiable. | Ordenar los datos antes de automatizar (cap. 11). |
| **F. Dinero y controles** | No hay separación de funciones ni límites escritos. | Matriz de autoridad (cap. 10). Conviene revisión de un profesional. |
| **G. Excepciones** | Lo excepcional no está registrado y por tanto no es transferible. | Registro de excepciones (cap. 8). |
| **H. Supervisión** | No existe un modo de saber cómo va la empresa sin estar dentro. | Tablero del propietario (cap. 19) y prueba de ausencia (cap. 24). |

## 9. Limitaciones del índice

Se enumeran para que usted sepa exactamente qué tiene en las manos.

1. **Es una autoevaluación.** Mide su percepción de lo que ocurre, no lo que ocurre. La
   segunda respuesta independiente corrige parte de este sesgo, no todo.
2. **No está validado.** No existe investigación que sostenga sus preguntas, sus pesos ni
   sus umbrales.
3. **Todas las dimensiones pesan igual.** Es una simplificación deliberada. En su empresa
   concreta, una dimensión puede importar mucho más que otra.
4. **No mide el riesgo, sino la dependencia.** Una empresa con dependencia crítica y un
   sector estable puede vivir años sin incidentes. La dependencia describe la exposición,
   no la probabilidad.
5. **Es sensible al momento.** Un mes con una crisis eleva artificialmente el resultado.
6. **No sustituye a un análisis de continuidad.** Existen marcos internacionales para eso,
   con otro alcance y otro coste.
7. **No dice nada sobre las personas.** Un valor alto no indica que el equipo sea débil.
   Casi siempre indica que nunca se le dio la información ni el permiso para decidir.

## 10. Qué hacer después de obtener el resultado

1. **Fechar y archivar.** Anote el total, los ocho subtotales y la fecha. Guarde también
   la respuesta de la segunda persona, si la hubo.
2. **Escribir las diez dependencias de mayor impacto.** No las veinticuatro: las diez que
   más dolerían si usted faltara un mes. Ordénelas.
3. **Elegir una sola dimensión para los tres primeros meses.** La más alta, salvo que otra
   sea más fácil de mover. Un avance real en una dimensión vale más que un avance
   simbólico en ocho.
4. **No comunicar el resultado como un diagnóstico del equipo.** No lo es. Si decide
   compartirlo, preséntelo como lo que mide: cuánto ha concentrado usted, y por qué motivos
   razonables.
5. **Fijar la fecha de la segunda medición** en el calendario, hoy, a seis meses vista.
6. **Continuar con el capítulo 2.** El índice dice cuánto depende la empresa de usted. El
   capítulo siguiente empieza a decir qué es exactamente lo que depende.
