# Inventario del conocimiento crítico

**Herramienta 3 de 18 · Capítulo 6 · Etapa L del Método LEGADO · Versión 1.0**

---

## 1. Para qué sirve

Para contestar **dónde** está la dependencia, después de que el Índice de Dependencia
contestara **cuánto**.

Produce una cosa concreta: **una lista ordenada de hasta diez dependencias prioritarias**,
cada una con su sitio actual y con lo que ocurre si no está disponible.

**Lo que esta herramienta no hace, y conviene tenerlo claro desde la primera línea:**

- **No documenta nada.** Si aparece «solo yo sé por qué rechazamos cierto tipo de encargo»,
  se anota esa frase y se pasa a la siguiente. El porqué se escribe más adelante, con otro
  instrumento.
- **No inventaría el negocio entero.** Busca dependencia relevante, no todas las tareas.
- **No evalúa a nadie.** La pregunta no es qué no sabe su gente. Es qué sigue concentrado en
  usted.
- **No puntúa.** No hay índices, ni porcentajes, ni niveles de riesgo calculados.

## 2. Cómo se usa

| | |
|---|---|
| **Quién la completa** | La persona de quien depende el negocio. |
| **Cuánto se tarda** | Una hora la primera vez. Menos si se revisa. |
| **Cada cuánto** | Cuando cambie algo relevante, y antes de volver a los capítulos de la Parte II. |
| **Qué hace falta** | Papel, y a mano el rastro de **una semana reciente y normal**: mensajes, llamadas, agenda, lo que aprobó, lo que buscó. |
| **Qué no hace falta** | Ningún programa. Ningún permiso. Nadie más. |

**Aviso sobre lo que escribe.** La hoja no necesita contener secretos para ser útil.
Escriba **«acuerdo especial con el cliente del contrato antiguo»**, no el acuerdo. No copie
aquí números de identificación, contraseñas, datos bancarios, datos de salud ni credenciales:
el inventario localiza dónde está algo, no lo reproduce.

## 3. Paso 1 — Buscar, con tres señales

No se busca en la memoria, porque lo que uno hace automáticamente no se presenta solo. Se
busca en el rastro de esa semana, con tres señales.

| | Señal | Con equipo | Trabajando solo |
|---|---|---|---|
| **1** | **Me lo preguntan** | Consultas, autorizaciones, asuntos que suben | Lo que llega de clientes y proveedores directamente a usted |
| **2** | **Yo lo recuerdo** | Dónde está algo, qué se acordó, qué pasó la vez anterior | Igual |
| **3** | **Yo lo decido** | Hay procedimiento y aun así pasa por usted, porque falta el criterio | Igual |

**Cuarta señal, solo si trabaja sin equipo: lo que solo usted sabe empezar.** Un encargo que
nadie más sabría por dónde arrancar es una dependencia aunque nadie le haya preguntado nunca
por él.

**Filtro, antes de anotar nada:** *si esto desapareciera mañana, ¿cambiaría algo que
importe?* Si no, no entra.

## 4. Paso 2 — La tabla

Seis columnas. No añada más: la hoja tiene que caber y tiene que terminarse.

| Elemento | Qué depende de esto | Dónde está hoy | ¿Quién más podría? | Si no está disponible | Prioridad |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |
| | | | | | |

**Elemento.** Una línea. El nombre, no la explicación.

**Dónde está hoy.** Una de estas cinco:

| | |
|---|---|
| **M** | Solo en mi memoria |
| **P** | Escrito a medias |
| **R** | Repartido entre correos, documentos y conversaciones |
| **D** | Documentado y localizable |
| **O** | Ya lo conoce otra persona, o lo resuelve un procedimiento |

**Existir no es estar disponible.** Algo que está en un correo de hace dos años existe, pero
si nadie sabe que existe ni dónde buscarlo, para el negocio no está. Las líneas **D** y **O**
se pueden tachar del inventario, y tacharlas es el mejor resultado posible.

**Si no está disponible.** Qué ocurre, sin convertirlo en dinero: se detiene algo, se bloquea
una decisión, se enfría una relación, se hace mal, se incumple un plazo o una obligación, se
pierde información. **El costo económico ya lo miró en el capítulo 4 y no se repite aquí.**

## 5. Paso 3 — Ordenar

Sin fórmula. Cruce dos preguntas y salen tres montones:

| | **Solo yo lo tengo** | **Alguien más podría** |
|---|---|---|
| **Si falta, algo se detiene o se hace mal** | **Alta** | Media |
| **Si falta, se retrasa o se resuelve peor** | Media | **Baja** |

Alta, media y baja son **criterios de lectura de este libro**, no una escala medida. Sirven
para poner las líneas en orden y para nada más.

**El medio no hay que afinarlo.** Nadie va a trabajar este mes en el elemento número doce.

## 6. Paso 4 — Los diez

De la lista ordenada, quédese con **hasta diez**.

**Diez es un límite práctico, no un número demostrado.** Es lo bastante para que el trabajo
tenga sentido y lo bastante poco para que se pueda hacer. Si le salen ocho, son ocho. Si
tiene claro que son doce, que sean doce. Lo que no funciona es quedarse con cuarenta, porque
cuarenta es lo mismo que ninguna.

## 7. La siguiente acción

Una sola, y es esta:

> **Coja los tres primeros de su lista y llévelos al capítulo siguiente.** Ahí verá dónde
> viven —en qué proceso, en qué decisión y en qué relación—, que es el paso que permite
> empezar a sacarlos de usted.

Y si quiere comprobar que la lista es la buena antes de seguir, hay una manera barata:
**durante los próximos cinco días, marque una raya cada vez que aparezca uno de los diez.**
Los que no aparezcan ninguna vez probablemente no eran los diez. Los que aparezcan cada día
son el primero y el segundo, se hubieran puesto donde se hubieran puesto.

**No empiece a documentar ninguno.** Es la tentación de este ejercicio y estropea las dos
cosas: se documenta mal y no se termina la lista.

## 8. Un ejemplo

Una mujer que lleva una tienda pequeña con dos empleadas revisa una semana normal y apunta
once elementos. Nueve son los que esperaba: qué se pide y en qué cantidad, qué clientes
tienen cuenta abierta, cómo se cierra la caja los sábados.

El décimo aparece por la señal 3, y es el que la sorprende. Cuando llega mercancía con un
defecto, ella decide si se devuelve, se rebaja o se acepta y se reclama después, y esa
decisión depende de con qué proveedor sea y de cómo fue la última vez. Sus empleadas saben
que existe la decisión. No sabrían tomarla.

En la tabla queda así: **elemento**, «qué hacer cuando llega mercancía defectuosa»; **dónde
está hoy**, M; **quién más podría**, nadie; **si no está disponible**, la mercancía se queda
parada esperando y se pierde el plazo de reclamación; **prioridad**, alta.

El undécimo es de otro tipo: hay un acuerdo verbal antiguo con un proveedor sobre plazos de
pago. Lo anota como **R** —vive en correos y en la memoria de dos personas— y no copia sus
condiciones en la hoja. Anota que existe, dónde buscarlo y qué pasa si nadie lo recuerda.

**Lo que no escribe en ninguno de los dos casos:** los nombres de las empleadas, el nombre
del proveedor ni las cifras del acuerdo. El inventario dice dónde está la dependencia; no la
copia.

## 9. Límites de esta herramienta

1. **No está validada.** Se construyó para este libro; alta, media y baja son criterios de
   lectura y no una medición.
2. **Depende de la semana que elija.** Una semana atípica da una lista atípica. Si duda,
   mire dos.
3. **No localiza lo que no dejó rastro.** Lo que usted resuelve sin que quede huella en
   ninguna parte es justamente lo más difícil de encontrar, y puede aparecer más adelante.
4. **No es un archivo ni un manual.** Si empieza a crecer sin parar, se ha convertido en otra
   cosa y conviene volver al filtro del paso 1.
5. **No sustituye a las herramientas 1 y 2.** El Índice mide, el Cuestionario sitúa a la
   persona, y este localiza. Son tres preguntas distintas.

> Esta herramienta es material educativo. No constituye asesoría legal, fiscal, laboral,
> financiera, contable, regulatoria ni de ciberseguridad. Los límites de autoridad, la
> conservación de documentos y el tratamiento de datos personales deben definirse con
> profesionales competentes según la jurisdicción de cada empresa.
