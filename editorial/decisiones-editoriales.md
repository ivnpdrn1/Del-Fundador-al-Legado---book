# Registro de decisiones editoriales

Toda decisión que afecte al título, la promesa, el método, la estructura, el tono o las
reglas del proyecto se registra aquí. Una decisión no registrada no existe.

**Estados:** `propuesta` · `aprobada` · `aprobada en parte` · `rechazada` · `revertida` ·
`reemplazada`

**`reemplazada`** significa que la decisión fue correcta cuando se tomó y que otra posterior
la sustituye. **No se borra ni se corrige**: se marca, se indica qué decisión la sustituye y
se conserva el razonamiento original.
